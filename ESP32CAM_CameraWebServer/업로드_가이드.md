# AR Glass — ESP32-CAM 펌웨어 업로드 가이드

두 눈 카메라(ESP32-CAM, AI-Thinker)에 **정식 `CameraWebServer` 펌웨어**를 넣는 방법입니다.

| 엔드포인트 | 역할 | 포트 | 상태 |
|---|---|---|---|
| `/stream` | MJPEG 스트림 (앱이 이걸 읽음) | **81** | 동작 |
| `/status` | 설정 JSON (`framesize/quality/...`) | **80** | 동작 |
| `/capture` | 정지 JPEG | **80** | 동작 |
| `/control` | 해상도·화질 제어 (앱이 자동 전송) | **80** | 코드엔 등록, **404 미해결** |

> - **포트 구조:** 스트림 서버 = `81`, 제어/상태 서버 = `80`. 앱은 스트림을
>   81번, `/status`·`/control`·`/capture`를 80번으로 나눠 접속합니다.
> - **fps 참고:** 지금 두 보드 모두 카메라 캡처 속도가 `약 0.3~2 fps` 로
>   매우 느린 상태입니다(큐피지가 아니라 캡처 자체, 하드웨어/드라이버급 원인
>   조사 중). 수신부(앱) 문제는 아닙니다. 이 부분은 별도 진행 중입니다.

## 프로젝트 구조

```
ESP32CAM_CameraWebServer/
├─ CameraWebServer/
│  ├─ CameraWebServer.ino   (메인: WiFi + 카메라 초기화)
│  ├─ wifi_config.h         ★ WiFi/보드별 IP 설정 (양쪽 보드 구분)
│  ├─ board_config.h        (카메라 모델: AI_THINKER)

│  ├─ camera_pins.h         (핀 맵)
│  ├─ camera_index.h        (브라우저 UI)
│  └─ partitions.csv
└─ flash.bat                (컴파일 + esptool 115200 자동 업로드)
```

## 준비물

- ESP32-CAM 1대 (한 번에 한 대씩)
- USB-TTL(CH340) 어댑터 1개 **또는** 기존의 ESP32-CAM 전용 프로그래머 보드 (CH340 내장)
- 점퍼 케이블 (전용 프로그래머 보드를 쓰면 **필요 없음**)
- PC 와 ESP32-CAM을 같은 WiFi(`ros5G`)에 연결해 둘 것

> 전용 프로그래머 보드(검은 캐리어)가 있으면 ESP32-CAM을 그냥 밀어 넣고
> USB만 연결하면 됩니다 — 점퍼 배선은 그 보드가 없을 때만 필요.

### 배선 (USB-TTL ↔ ESP32-CAM)  — 점퍼를 쓸 때만

| USB-TTL(CH340) | ESP32-CAM |
|---|---|
| 5V | 5V |
| GND | GND |
| TX | U0R (RX) |
| RX | U0T (TX) |

> ESP32-CAM은 5V 파워가 필요(촬영 시 5V에서 3.3V 레귤레이터 사용).
> USB-TTL의 3.3V만 쓰면 부팅 불안정.

## 부팅모드 (IO0 + RESET)

전용 프로그래머 보드(CH340 캐리어)는 **DTR/RTS 자동 리셋**이 되어 있어
`flash.bat`(esptool)이 알아서 부팅모드로 전환합니다 — **버튼 불필요**.

USB-TTL 점퍼 배선을 쓸 때만 아래 순서를 해 줍니다.

1. **IO0** 를 누른다 (보드 위 GPIO0 버튼)
2. IO0 누른 상태에서 **RESET** 을 살짝 눌렀다 뗀다
3. RESET 후 **IO0 를 뗀다** → 업로드 대기 상태
4. 업로드가 끝나면 RESET 한 번 눌러 정상 부팅

### 업로드 속도 (중요)

esptool 기본 460800baud 로는 이 보드에서
`Unable to verify flash chip connection` 오류가 납니다.
**115200 baud**로 쓰면 자동으로 성공합니다. (`flash.bat`이 115200 사용)

## 방법 A) 배치 파일로 업로드 (권장)

더블클릭: **`flash.bat`**

1. LEFT 보드를 PC에 연결 (전용 프로그래머 보드는 그냥 꽂으면 됨)
2. `flash.bat` 실행 → COM 포트 입력 (CH340 = COM25/COM26 중 장치관리자에서 확인)
3. 컴파일 + esptool 115200 업로드 자동 진행 → **[OK]** 확인 (약 70초)
4. **RIGHT** 보드로 교체
5. `CameraWebServer\wifi_config.h` 열어서 아래를
   ```
   #define AR_GLASS_BOARD  0   →   #define AR_GLASS_BOARD  1
   ```
   로 바꿔 저장
6. RIGHT 보드를 연결하고 `flash.bat` 다시 실행

> `arduino-cli` 는 Arduino IDE 2.x 기본 설치 경로를 자동 사용합니다.
> IDE 2.x가 없으면 방법 B로.

---

## 방법 B) Arduino IDE (GUI)

1. **Arduino IDE 2.x** 설치 (기본 경로)
2. 파일 → 환경설정 → 추가 보드 매니저 URL에
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json` 추가
3. 보드 매니저에서 **esp32 by Espressif** 설치 (v3.x)
4. 이 프로젝트의 `CameraWebServer\CameraWebServer.ino` 더블클릭
5. 도구:
   - 보드: **AI Thinker ESP32-CAM** (없으면 ESP32 Wrover Module / ESP32 Dev Module)
   - Partition Scheme: 기본값 (3MB APP)
   - 포트: CH340 COM 선택
6. **톱니 버튼(검증)** → 컴파일 OK 확인
7. 보드 부팅모드로 만들고 **→(업로드)**
8. 끝나면 RESET 한 번

> 업로드가 `Unable to verify flash chip connection` 으로 실패하면
> 도구 → **Upload Speed 를 115200** 으로 바꾸고 다시 시도.

RIGHT 보드에서는 `wifi_config.h`의 `AR_GLASS_BOARD`를 `1`로 바꾼 뒤 다시 업로드.

## 업로드 후 확인

```bat
cd C:\Users\user\Desktop\AR_Glass_Robot_Control
python -m ar_glass.checkip 192.168.0.137
python -m ar_glass.checkip 192.168.0.69
```

- `[2] 펌웨어 /status OK  framesize=... quality=...` 가 나와야 합니다.
- 라이브 태그 검출:
  ```bat
  python -m ar_glass.checkip --live --save snapshots 192.168.0.137
  ```
  태그를 카메라 앞에 대면 `ID ... 500mm conf 0.9x` 형태로 감지됩니다.

### 확인 중인 이슈

- `/control`이 404를 반환합니다(등록 코드는 있음). 원인이 해결되면
  앱 시작 시 자동 해상도 전환이 가능해집니다.
- 카메라 캡처가 `~1 fps` 수준으로 느립니다(하드웨어/드라이버 조사 중).

### IP가 바뀌면?

정적 IP를 썼다면 바뀌지 않습니다 (`LEFT=192.168.0.137`, `RIGHT=192.168.0.69`).
DHCP로 두었다면(`USE_STATIC_IP 0`) 앱 설정에서 IP만 다시 입력하거나
`config\settings.json`의 `host` 값을 수정하세요.

## 설정 요약 (`wifi_config.h`)

| 항목 | 값 | 설명 |
|---|---|---|
| `WIFI_SSID` | `ros5G` | WiFi 이름 |
| `WIFI_PASSWORD` | `rosrosros` | WiFi 비밀번호 |
| `AR_GLASS_BOARD` | `0`(LEFT) / `1`(RIGHT) | 보드별 IP/구분 |
| `STATIC_IP_ADDRESS` | `.137` / `.69` | 보드별 고정 IP |
| `STATIC_IP_GATEWAY` | `192.168.0.1` | 라우터 게이트웨이 |
| `USE_STATIC_IP` | `1` | DHCP로 두려면 `0` |
